# Phase 2: Baseline Agents And Access

## Goal

Add a small specialist-agent set and make the system easy to use remotely.

## Epics

1. Default assistant profile
2. Coding agent
3. Thinking and research agent
4. Management and operator agent
5. Remote access posture

## Exit Criteria

- the default assistant can hand work off
- agent responsibilities are explicit
- remote use does not depend on the local workstation being the only execution surface
