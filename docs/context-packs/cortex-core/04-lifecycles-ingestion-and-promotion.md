# Lifecycles, Ingestion, And Promotion

## Live Session To Memory

1. OpenClaw runs the session.
2. Layer 5 captures `runtime_evidence`.
3. `QMD` stores hot continuity and notions.
4. boundary-triggered semantic processing emits typed outputs.
5. reflection updates Layer 2 and Layer 4.
6. reconciliation promotes durable meaning into Layer 3 when warranted.

## Many Threads To One Workspace

1. repeated fragments accumulate across threads
2. Layer 3 links them through concept or idea-cluster structure
3. Layer 4 holds the evolving workspace body
4. promotion happens only later if canon is warranted

## External References

1. Layer 5 retains the source as `reference_cache` when needed
2. Layer 4 holds bounded derived knowledge
3. Layer 3 stores only durable meaning that matters

External references do not automatically become authored canon.

## Owned Sources

Owned sources are stronger than generic references.

They support later dirty-state, reprocessing, and source-maintenance flows.

## Promotion And Reprocessing

1. a Layer 4 body matures
2. Layer 3 support and relationship structure indicate readiness
3. Layer 5 receives an `authored_artifact`
4. later authored revision can trigger re-ingestion back into Layer 4
5. Layer 3 reconciles support, summaries, and supersession

Promotion is not normal ingestion.

## Multi-Party Continuity

Chronicles, needs workspaces, and coordination dossiers are Layer 4 bodies.

Layer 3 stores the relationships, approvals, and support structure around them.

Layer 5 stores the evidence behind them.
