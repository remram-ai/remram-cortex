# Phases And Delivery

## Delivery Sequence

- `Phase 0`: vanilla OpenClaw baseline with `QMD`
- `Phase 1`: chat-derived Cortex memory loop
- `Phase 2`: one-way reference decomposition
- `Phase 3`: owned-source maintenance and dirty-state semantics
- `Phase 4`: authored artifact promotion and canonical reprocessing
- `Phase 5`: `Mamba`, `Intuition`, and optimization

## Immediate Build Target

The current target is `Phase 0` plus `Phase 1`.

That means:

- prove the OpenClaw baseline cleanly
- capture chat transcripts through Layer 5
- use boundary-triggered semantic processing
- stage notions in `QMD`
- materialize narrow Layer 4 support bodies
- reconcile trusted durable memory into Layer 3

## What Is Explicitly Deferred

- `Mamba`
- `Intuition`
- `OpenSearch`
- Git-backed authored canon before the promotion phase
- broad document or artifact work beyond the current phase

## Sequencing Rule

The architecture is already valid before `Mamba`.

Phase 5 improves an already-working spine. It does not rescue an incomplete one.
