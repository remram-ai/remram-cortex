# Terminology And Legacy

## Current Core Terms

- `Policy`: Layer 1 behavioral truth.
- `Working Memory`: Layer 2 hot continuity.
- `Durable Memory`: Layer 3 semantic truth.
- `Operational Knowledge`: Layer 4 operationally authoritative bodies.
- `Evidence`: Layer 5 source-of-record bodies.
- `Notion`: hot staged candidate durable memory in `QMD`.
- `Authored Artifact`: the precise Layer 5 canon-class evidence term.
- `Reference Cache`: Layer 5 class for retained external references.
- `Runtime Evidence`: Layer 5 class for session and tool evidence.
- `Workspace`: medium-horizon Layer 4 operational body.
- `Chronicle`: longitudinal Layer 4 continuity body.
- `Governance Scope`: bounded scope carried through governance fields.

## Important Language Rules

- `Context` means bounded runtime injection, not Layer 2 or memory in general.
- `Artifact` is an umbrella term. Use the exact evidence class when precision matters.
- `Dream` is the preferred short form. `Dream Cycle` is still acceptable.
- `Authored canon` is acceptable shorthand, but `authored_artifact` is the formal Layer 5 evidence-class name.

## Retained Or Deferred Terms

- `Typed Signals`: retained retrieval concept, not locked Phase 1.
- `Semantic Signature`: retained routing concept, not locked Phase 1.
- `Conversation Layer`: deferred concept, not part of MVP 1.

## Legacy Terms

- `Dimension`: legacy umbrella term replaced by `Governance Fields`, `Typed Signals`, and `Semantic Signature`.

## Practical Reminder

If a term sounds stable but is actually tentative or deferred, say so explicitly.
