# Phase 3: Dev/Test Loop

## Goal

Make iteration repeatable.

## Epics

1. Local-to-remote development workflow
2. Test-lane deployment and validation
3. Logs and diagnostics
4. Rollback posture
5. Sandbox or coding-environment integration

## Exit Criteria

- changes can be tested predictably
- validation uses supported Moltbox surfaces
- logs and rollback are explicit
