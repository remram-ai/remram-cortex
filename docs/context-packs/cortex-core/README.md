# Cortex Core Context Pack

This is the compact authority-first AI context pack for `remram-cortex`.

Use it when you want a new thread to load the right mental model quickly without pulling the whole repository.

## Pack Goal

Give a fresh reader enough context to avoid the common category errors:

- confusing context with memory
- treating Layer 3 as a body store
- treating Layer 4 as a projection instead of an authority
- treating Layer 5 as "Git only"
- assuming `Mamba` is required before the architecture is real
- assuming `OpenSearch` is active
